# Real-Time & Batch Financial Data Platform

An end-to-end Data Engineering pipeline built with Python, PySpark, Apache Airflow, and PostgreSQL.

## Architecture Overview
- **Ingestion:** Python & REST APIs
- **Orchestration:** Apache Airflow
- **Processing:** PySpark / DuckDB
- **Storage:** Parquet / Local S3 Lakehouse
- **Warehouse:** PostgreSQL Dimensional Model (Star Schema)
